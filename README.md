# TV Music

面向 Android TV / 电视盒子的音乐播放器，遥控器优先，大屏 960×540dp 基准设计，支持 4K 缩放与三档字号。

当前版本 **0.9.1 · M4**：新增**本地库**（MediaStore / SAF 文件夹 / SMB 共享）与**音源市场**——设备音频直接入队播放，SMB 凭据加密后只读流式播放，音源脚本从远程清单校验 SHA-256 后安装并重载。M3c 的在线更新、M3b1 的下载/离线库、M3a 的手机伴侣、M2 的逐字歌词与 M1 的搜索/后台播放继续保留。

> 本仓库不包含任何音源脚本、音频或歌词文件。本地构建会把用户放在仓库根目录 `音源/` 下的 `*.js` 注入 APK 供自用；开源构建不注入脚本。README 末尾有版权与许可说明。

## M4 已实现（本地库、SMB 与音源市场）

### 设备音乐与文件夹

- **入口**：首页“本地音乐”是本地中枢，分“设备歌曲”和“下载管理”；设置 → 本地库也可进入。
- **MediaStore**：Android 13+ 申请 `READ_MEDIA_AUDIO`，旧版申请 `READ_EXTERNAL_STORAGE`；只收录系统标记为音乐且时长 ≥ 20 秒的音频，保存标题/歌手/专辑/时长与 `content://` URI，不复制文件。
- **文件夹导入**：系统目录选择器（SAF）持久化读取授权，递归扫描子目录（最多 8 层、5000 首），支持 mp3/flac/m4a/aac/ogg/wav/opus。
- **播放**：OK 直接播放并进入播放页；本地曲目与在线曲目共用播放队列、MediaSession、后台播放与媒体键；本地曲目没有歌词时明确显示“本地歌曲暂无歌词”。
- **索引**：`files/local/library.json`，重启后恢复；设备扫描会保留文件夹与 SMB 来源的曲目。

### SMB 共享

- **配置**：在 U 盘/手机上准备 `smb.json`，通过系统文件选择器导入：
  `{"name":"NAS","host":"192.168.1.10","port":445,"share":"music","path":"/","domain":"","user":"tv","password":"******"}`
- **凭据安全**：用户名/密码用 AndroidKeyStore 的 AES-GCM 密钥加密后保存；界面只显示主机、共享名与用户名，日志不输出密码。
- **扫描**：jcifs-ng 直连 SMB2.0.2–SMB3.1.1，递归列出共享中的音频（最多 8 层、2000 首），结果并入设备歌曲并持久化；连接失败会给出“用户名或密码错误 / 共享拒绝访问 / 无法连接”等可读原因。
- **播放**：`smb://` 由自定义 Media3 DataSource 按需读取，支持 Range 定位与 seek，不复制文件；清除配置需 3 秒内二次确认，并同时移除 SMB 曲目索引。
- **建议**：给电视单独建只读账号，只共享音乐目录；SMB 依赖局域网，跨网段/NAT 不一定可达。

### 音源市场

- **入口**：设置 → 音源 → 音源市场。
- **清单**：根目录 `sources.json` 的 `sources` 数组，每项包含 `id / name / version / author / description / url / sha256`；默认从 jsDelivr 读取，失败回退 raw.githubusercontent.com 与 cdn.jsdelivr.net。
- **安装**：只接受 HTTPS（debug 允许 HTTP）；脚本必须带 64 位 SHA-256，单文件 ≤ 8 MB；下载后校验哈希，写入 `files/lx_user_js` 并自动重载 LX 引擎；重复安装会提示已安装。
- **确认**：安装按钮 3 秒内二次确认，避免误触；失败原因（地址、哈希、写入、重载）显示在胶囊提示与列表中。
- 本仓库的 `sources.json` 为空，只提供清单格式，不分发音源脚本。

## M3c 已实现（在线更新）

### 检查与安装

- **入口**：设置 → 更新。进入分组会自动检查一次，也可随时点“检查更新”。设置卡显示当前版本、状态、更新说明、包体大小与下载进度。
- **清单**：`update.json` 提供 `versionCode / versionName / apkUrl / sha256 / sizeBytes / notes`；只有 `versionCode` 大于当前版本才会提示更新。默认地址为 jsDelivr 镜像，失败时依次回退到 raw.githubusercontent.com 与 cdn.jsdelivr.net；请求带短时缓存参数。
- **下载**：显示百分比、已下载/总大小，可取消；下载到应用私有 `files/updates/`，完成后校验 SHA-256、APK 包名、`versionCode` 必须更高、签名必须与当前应用一致，任一失败都会删除安装包并显示原因。
- **安装**：通过 FileProvider 把 APK 交给系统安装器（`ACTION_VIEW` + `application/vnd.android.package-archive`），首次需要允许本应用“安装未知应用”；未授权时自动打开该设置页，返回后再点“安装更新”。应用不会静默安装。
- **安全**：正式版只接受 HTTPS 清单与安装包（debug 构建才允许 HTTP，便于本地验证）；安装包存储在应用私有目录，FileProvider 只暴露 `updates/`；签名校验保证不能被其他签名的 APK 覆盖。

### 发布新版本

1. 提升 `app/build.gradle.kts` 的 `versionCode` / `versionName`，构建 release APK。**上传到公开渠道的 APK 不要包含 `音源/` 脚本**（本地自用包也不要上传）。
2. 计算 SHA-256 与字节数：`sha256sum app-release.apk`、`stat -c%s app-release.apk`。
3. 把 APK 放到稳定的 HTTPS 地址（GitHub Release 资产或自己的静态站点），编辑根目录 `update.json` 的六个字段并提交。
4. 客户端默认从 `https://testingcf.jsdelivr.net/gh/Zxxy326/TV-Music@main/update.json` 读取；jsDelivr 有缓存，必要时用 raw.githubusercontent.com 或构建时覆盖清单地址：
   `./gradlew :app:assembleRelease -Ptvmusic.updateManifest=https://example.com/update.json`
5. 本地联调可用 `-Ptvmusic.versionCode=11 -Ptvmusic.versionName=0.9.2-test` 构建一个更高版本的同签名 APK，再用本机 HTTP 服务与 debug 包验证完整升级。

0.9.1 已公开发布：`update.json` 指向 GitHub Release 的公开包（不含 `音源/` 脚本，SHA-256 与大小已写入清单）。本机的 0.9.1 自用包包含脚本，按仓库规则不上传公开渠道；通过“设置 → 更新”下载安装的是公开包，覆盖升级会保留应用数据与已导入到 `files/lx_user_js` 的音源脚本。0.9.0 及更早版本可在线升级到 0.9.1，已经安装 0.9.1 的会显示已是最新。

公开包地址：<https://github.com/Zxxy326/TV-Music/releases/tag/v0.9.1-m4>

## M3b1 已实现（下载与离线库）

### 下载

- **入口**：播放页按 ↑ 打开控制条，最左侧新增下载按钮（演示曲目不显示）。点击后按当前音质设置取流并下载，按钮随状态变为“下载中 / 已下载”，再点会提示进度或播放位置。
- **状态**：准备中 → 下载中（本地音乐页显示百分比、已下载大小与进度条）→ 已下载 / 下载失败。失败保留原因，点行可重试；下载中按 MENU 可取消。
- **存储**：保存到应用专属外部目录 `Android/data/tv.music.player/files/Music/downloads`（debug 包为 `tv.music.player.debug`），索引写入同目录 `downloads.json`；文件名按“歌名 - 歌手”清洗，扩展名按响应类型/URL 推断。卸载应用或清除数据会一并删除。
- **离线播放**：播放器优先读取本地文件，已下载歌曲不再走 LX 取流；`file://` 播放通过 `DefaultDataSource` 支持，飞行模式下实测可播。
- **本地音乐页**：首页“本地音乐”进入，显示已下载歌曲与总占用；OK 播放，MENU 第一次提示“再按一次”（2.5 秒内），第二次才删除；正在播放的歌禁止删除。
- **并发与质量**：同时最多 2 个下载任务；下载使用当前音质，`高音质` 约 10 MB/首，`无损` 可能 50 MB/首。HLS（`.m3u8`）音源会明确拒绝，避免只存到播放列表。

## M3a 已实现

### 手机伴侣

- **局域网服务**：应用内启动轻量 HTTP 服务（默认端口 `8390`），手机与电视连同一 Wi-Fi / 局域网即可访问；服务随“手机伴侣”开关启动/停止，进程退出即关闭。
- **配对**：电视端显示二维码与 4 位配对码，二维码 URL 自带配对码；手机首次打开需输入配对码，之后保存在手机 localStorage。配对码 30 天自动过期，也可在电视端手动更换。
- **输入同步**：手机输入歌名/歌手或点击热搜词，电视自动打开搜索页并执行 QQ 搜索；手机与电视的搜索历史同步落盘。
- **遥控**：手机网页显示当前歌曲、歌手/专辑、进度与队列；支持播放/暂停、上一首、下一首、快退/快进 10 秒、拖动进度条 seek、点击队列任意一首点播。
- **页面**：单文件响应式深色页面，无外部 CDN；使用 `fetch` 轮询 `/api/state`，所有控制接口需配对码。电视端设置卡显示服务状态、二维码、局域网 URL、配对码，并提供“换配对码 / 刷新地址 / 关闭”按钮。
- 电视首页新增 **MENU 打开设置** 快捷键，解决设置齿轮方向键不可达的问题。

## M1b 已实现

### 搜索输入与结果

- **拼音 T9**：九宫格 2–9 映射 ABC…WXYZ，连按同键循环字母，支持全拼与首字母；数字键和屏幕九宫格共用多击逻辑。MENU 在拼音/数字输入间切换。
- **联想候选**：输入纯字母时请求 QQ 搜索的 `qc` 联想，显示“猜你想搜”中文候选；选中后直接以中文搜索。
- **历史与分页**：搜索历史写入 SharedPreferences（最多 8 条，可清空）；结果每页 30 首，底部“加载更多”按页追加并去重，显示已加载数量与总条数。
- 仍由 QQ 原生搜索提供元数据，本机 LX 脚本负责解析播放地址。

### 收藏与最近播放

- 播放页控制条新增收藏/取消收藏按钮，顶部信息区显示“已收藏”状态；收藏页可播放全部收藏。
- 播放成功后自动记录最近播放，去重并保留 30 首；首页“继续听”直接读取最近播放，最近播放页可回看和整队播放。
- 数据写入应用私有目录的 `library/favorites.json` 与 `library/recent.json`，进程重启后保留。暂未引入 Room，后续与本地曲库一起迁移。

### 后台播放与系统控制

- 新增 `PlaybackService`（MediaSessionService）+ MediaSession；应用启动时连接 `MediaController`，在线歌曲播放时自动转为前台服务并显示媒体通知。
- 通知栏支持播放/暂停、上一首、下一首；系统媒体键和蓝牙媒体键同样生效（下一首/上一首会回到 LX 解析链路重新取流）。
- 通知标题/歌手/专辑/封面来自当前 MediaItem；点通知回到播放器。Android 13+ 首次启动会请求通知权限。
- 演示曲目没有真实音频 URL，不产生媒体通知；在线歌曲走完整 MediaSession 链路。

### 音源导入与测试

- “设置 → 音源”提供“导入脚本”：调用系统文件选择器从 U 盘/下载目录选择 `.js`，写入 `files/lx_user_js` 后自动重载；脚本无效时自动回滚并重新加载。
- “源测试”用 QQ 搜索的《晴天》元数据逐源调用 `getPlayUrl`，显示每个源的取流延迟与失败原因（单源 20 秒超时）。
- 引擎页显示已加载脚本数、注册源数量与脚本版本，可一键重新加载。

## M2b 已实现

### 歌词与逐字（M2a/M2b）

- **歌词来源**：QQ `musicu` 接口取回 LRC 与翻译，`lyric_download` 取回 QRC 逐字歌词，两路并行；失败回落旧版 `fcg_query_lyric_new`。结果按 songmid 做内存 LRU 缓存。
- **逐字 QRC**：QQ 改版 DES（S2 盒与标准不同）三段解密 → zlib → UTF-8/GB18030 自适应解码；搜索 songid 全链路透传，逐字时间轴优先于逐行 LRC。
- **解析能力**：标准 LRC 多时间戳、`[offset:]`、`主词//翻译` 行内格式；QRC `[行开始,时长]词(开始,时长)` 逐字解析，翻译按时间从 LRC 合并；方言罗马音字段为加密内容，暂忽略。
- **八种样式**：经典逐行、大字幕、极简纯文字、卡拉OK扫色（未唱灰、已唱主题色，逐字推进）、弹跳气泡（当前字弹性放大 + 圆角气泡）、双语对照（主词扫色 + 翻译副行）、黑胶唱片（旋转唱片 + 唱臂）、沉浸光晕（呼吸光晕 + 超大当前句）。无逐字数据时自动退化为逐行高亮。
- **样式轮盘**：歌词面板中的横向轮盘会把当前项平滑滚到中间，每个样式带一张示意图预览；← → 循环 8 种样式与操作项。
- **歌词面板**：播放页按 **MENU** 打开；← → 选择、OK 执行，可切样式、开关翻译、按 ±0.5s 调整偏移（±5s）、重新获取、手动匹配；设置页外观组同样可调。
- **播放布局**：布局 A 全屏歌词；布局 B 左侧封面轨（封面、歌名、专辑、进度、音质/队列）加右侧歌词。极简/黑胶/沉浸强制全屏。
- **手动匹配**：面板选“手动匹配”后列出 QQ 搜索候选（歌名/歌手/songmid），↑↓ 选择、OK 使用、返回取消；首行“自动匹配”恢复原生歌词。选择按 songmid 持久化，下次播放同一首歌直接命中。
- **歌词磁盘缓存**：歌词序列化到 `cacheDir/lyrics`，14 天过期、最多 240 首、临时文件原子替换；“重新获取”会绕过缓存重新联网。
- **状态处理**：加载中、无歌词、纯音乐、获取失败分别提示，不阻塞播放。

### M1a 能力

- **LX QuickJS 引擎**：移植自参考项目，支持多脚本独立上下文、`lx.request` 异步 HTTP、crypto/buffer、定时器、musicUrl 动作、同名源多脚本轮询。
- **本地音源**：构建时自动把 `音源/*.js` 同步到 assets，首次启动复制到应用私有目录；设置 → 音源可查看已加载脚本、注册源，并一键重新加载。
- **QQ 音乐搜索**：原生 zzcSign + QQ 搜索接口，返回歌名/歌手/专辑/时长/封面/ songmid 等元数据，30 首一页。
- **真实播放**：LX 脚本解析 URL → URL 探活 → Media3 ExoPlayer 播放；320k 失效自动尝试 flac / 128k；播放失败有顶部胶囊提示。
- **连续播放**：搜索结果的 30 首自动成为播放队列，下一首/上一首/队列切歌都会重新解析音源。
- **播放页**：真实进度/时长、暂停/续播、±10s、控制条、队列，以及真实歌词与翻译。
- M0 能力保留：焦点记忆、跨 Rail 列索引、设置持久化、搜索/播放返回栈、长按返回首页、迷你播放条自动隐藏。

## 构建与安装

环境：JDK 17、Android SDK Platform 36、Android SDK Build-Tools 36。

```bash
# 可选：把自用音源放到仓库根目录 音源/*.js，构建时会自动注入
./gradlew :app:assembleDebug
./gradlew :app:assembleRelease

# 公开渠道使用：不注入任何音源脚本（同时清空 assets/lx）
./gradlew :app:assembleRelease -Ptvmusic.bundleLocalSources=false
```

产物：

- Debug：`app/build/outputs/apk/debug/app-debug.apk`（包名 `tv.music.player.debug`）
- Release：`app/build/outputs/apk/release/app-release.apk`（包名 `tv.music.player`）

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```

`音源/` 与同步生成的 `app/src/main/assets/lx/` 均已加入 `.gitignore`，不会进入开源仓库。Release 目前沿用 debug 签名，仅用于自测与真机试用；正式分发前请配置自己的签名。

## 已知限制（M4）

- 更新必须由用户在系统安装器里确认，不能静默安装；首次需要允许本应用“安装未知应用”。个别电视盒子没有可用的安装器界面，会提示无法启动。
- 更新包必须与当前安装包使用同一签名。以后若从 debug 签名切换到正式 keystore，旧版本无法在线覆盖升级，只能卸载重装（应用数据会丢失）。
- 清单与 APK 依赖 jsDelivr / GitHub 或自建静态站点；jsDelivr 缓存可能延迟。只做整包更新，没有增量更新；正式版拒绝 HTTP 地址。GitHub Release 的 APK 下载在部分网络环境可能被阻断或很慢，此时需要代理或手动下载公开包安装。
- 更新下载随 App 进程存活，没有 WorkManager/前台下载服务；进程被杀会中断下载。已完成的安装包会保留，重新进入更新页检查后可直接安装。
- 公开分发的 APK 不要包含 `音源/` 脚本（本仓库规则）；`update.json` 中的哈希与版本号必须与实际包一致，否则客户端会拒绝下载或校验失败。

- 手机伴侣仅面向可信局域网：HTTP 明文、4 位配对码，没有 HTTPS、账号或设备白名单；不要暴露到公网。服务随 App 进程存活，进程被杀后需重新打开电视端。
- 手机遥控页是浏览器页面，没有原生 App/PWA 安装；部分电视/路由开启 AP 隔离时手机无法访问电视。
- 二维码只编码第一个检测到的局域网 IPv4；多网卡/多网段时可在电视端点“刷新地址”，必要时手动输入其他地址。
- 下载随 App 进程存活，没有前台下载服务/WorkManager：切走应用或锁屏后若进程被系统回收，未完成任务会中断，需重新点击；暂不支持暂停/断点续传、Wi-Fi-only 与独立下载队列。
- 只支持单文件音频（mp3/flac/m4a/ogg 等）；HLS 流、加密格式与需要特殊请求头的音源可能无法下载。下载质量跟随全局音质设置，暂无逐曲选择。
- 下载目录是应用专属外部目录，卸载/清除数据即删除；文件管理器在 Android 11+ 可能无法直接访问该目录。失败记录不持久化，重启后需重新下载。
- MediaStore 只索引系统媒体库已扫描、时长 ≥ 20 秒的音频；部分 U 盘需要先由系统扫描或改用“添加文件夹”。SAF 授权在卸载/清除数据后失效，最多 8 层 / 5000 首，不读取压缩包内音频。
- SMB 只在模拟器验证了配置导入、凭据加密与连接失败提示，尚未在真实 NAS 上验收流式播放；SMB1、DFS、要求特殊签名/加密的共享可能不可用；当前只支持单个共享根目录，没有浏览式挂载或写回。
- SMB 凭据绑定本机 AndroidKeyStore，换机或恢复备份后需重新导入 `smb.json`；清除配置会同时移除 SMB 曲目索引。
- 音源市场依赖外部 HTTPS 清单与脚本，本仓库 `sources.json` 为空；目前只能安装，尚无启停、排序、卸载与版本升级提示，清单中的 `sha256` 必须与实际文件一致。
- 音频读取权限被永久拒绝后，需要到系统设置手动授权；应用内只提示失败原因，不提供一键跳转。
- 账号扫码、Cookie 导入与歌单同步仍未接入（M3b2）。
- 拼音输入采用九宫格多击（连按同键换字母），不是完整的拼音组合/中文词库；候选来自 QQ 联想，离线时只能直接搜字母。
- 歌词逐字翻译（QQ 仅提供行级翻译）、罗马音、歌词海报尚未实现；手动匹配依赖 QQ 在线搜索，候选受平台结果限制。
- 极简、黑胶、沉浸三种样式不支持布局 B；布局 B 的左轨信息在极小字号下会压缩。
- 歌词磁盘缓存固定 14 天 / 240 首，暂未提供清理入口；歌词偏移为全局设置，暂无逐曲偏移。
- 收藏/最近播放使用 JSON 文件持久化，尚未迁移 Room；收藏页不提供直接删除，需回播放页点心形按钮。
- 音源导入通过系统文件选择器选择 `.js`；音源市场已接入，但 URL 直接安装、启停排序与卸载仍未实现。源测试使用 QQ 元数据，部分源无法跨源解析属于预期结果。
- MediaSession 后台播放与通知栏已在模拟器验证；演示曲目没有真实 URL，不产生媒体通知。Android 13+ 需授予通知权限。
- Release 使用 debug 签名、R8 关闭，包体偏大；4K 缩放逻辑已接入，尚未在 4K 真机逐项验收。
- 已在 1080p 横屏模拟器（SwiftShader 软件渲染）验证交互、导入、分页、媒体键，手机伴侣的配对、输入同步、队列点播、暂停与 seek，下载、重启后索引恢复、飞行模式离线播放和 MENU 二次确认删除，在线更新的检查、下载、SHA-256/签名校验与系统安装器覆盖升级，设备音乐扫描与 `content://` 播放，音源市场的下载/哈希校验/安装重载，以及 SMB 配置导入、凭据加密与连接失败提示；SMB 流式播放尚无真实 NAS 验收，模拟器帧率数据不代表真机。
